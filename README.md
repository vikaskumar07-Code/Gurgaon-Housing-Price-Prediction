# Gurgaon-Housing-Price-Prediction
End-to-end machine learning project for housing price prediction using Scikit-learn

# Project Overview
This project is an end-to-end machine learning solution for predicting housing prices based on various features such as location, income level, and housing attributes.  
The objective is to build a robust and reusable regression pipeline that can be used both for training and inference.

The project follows **industry-standard machine learning practices**, including data preprocessing pipelines, model persistence, and separation of training and inference logic.

# Problem Statement
Real estate prices are influenced by multiple factors such as location, income distribution, and property features.  
This project aims to predict the **median house value** using historical housing data to assist stakeholders in making data-driven pricing decisions.

# Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

# Dataset
- **Dataset**: Housing dataset (used for Gurgaon housing price analysis)
- Includes:
  - Numerical features (e.g., median income, rooms, population)
  - Categorical feature (`ocean_proximity`)
- Target variable:
  - `median_house_value`

# Approach
1. Data loading and initial exploration
2. Creation of income categories for **stratified sampling**
3. Train-test split using `StratifiedShuffleSplit` to avoid sampling bias
4. Feature separation:
   - Numerical features
   - Categorical features
5. Data preprocessing using Scikit-learn pipelines:
   - Median imputation for missing numerical values
   - Standard scaling for numerical features
   - One-hot encoding for categorical features
6. Model training using **Random Forest Regressor**
7. Saving trained model and preprocessing pipeline using `joblib`
8. Inference on unseen data and saving predictions to CSV

# Machine Learning Model
- **Algorithm**: Random Forest Regressor
- Handles non-linear relationships effectively
- Robust to outliers and feature interactions
- Suitable for structured tabular data

# Model Artifacts
The trained model and preprocessing pipeline are saved locally as `.pkl` files using `joblib`.

> **Note:**  
Due to GitHub file size limitations, trained `.pkl` files are excluded from this repository using `.gitignore`.  
They can be regenerated by running the training script locally.
